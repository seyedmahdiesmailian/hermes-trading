## مراحل رستور روی سرور جدید

### مرحله ۱: نصب Hermes تازه
```bash
# Hermes رو نصب کن (طوریکه برای اولین باره)
hermes-setup.exe
# یا از MSI/Zip — هرچی نصبگر اصلی داری
```

### مرحله ۲: پر کردن API Keys
⚠️ **فایل `.env` در بکاپ ماسک شده است** (کلیدها با `***` جایگزین شدن). باید دستی پرشون کنی:

```bash
notepad "%LOCALAPPDATA%\hermes\.env"
```

موارد ضروری:
- `FIREWORKS_API_KEY=`
- `OPENROUTER_API_KEY=`
- هر کلید مربوط به OmniRoute (اگه لازمه)

### مرحله ۳: کپی فایلهای بکاپ
بعد نصب تازه Hermes (قبل هیچ چت نخورده)، کل فولدر بکاپ رو بریز توی:
```
%LOCALAPPDATA%\hermes\
```

> **مهم:** Hermes باید کاملاً بسته باشه در حین کپی. `hermes-desktop.exe` رو از Task Manager بکش بیرون.

### مرحله ۴: راهاندازی مجدد
```bash
hermes-desktop.exe
```

### مرحله ۵: اعتبارسنجی
بعد باز شدن:
1. بگو `سلام` — باید بلافاصله بشناسهت (مهدی، کارشناس شبکه، ...)
2. کرون جابها رو چک کن: `hermes cron list`
3. کانکشن تلگرام/دیسکورد رو چک کن
4. یه اسکیل ترید رو امتحان کن

## نکات طلایی

1. **اگر میخوای شروع تمیز بدون چت قدیمی** → `state.db` و `sessions/` رو نریز. فقط `memories/` و `skills/` و `config.yaml` رو بریز.

2. **اگر میخوای همه چت قدیمی مونده** → کل بکاپ رو کپی کن.

3. **Cron jobs بعد رستور** → باید `state` شون رو چک کنی (ممکنه `paused` باشن). با `hermes cron list` ببین، با `hermes cron resume JOB_ID` فعالشون کن.

4. **Telegram Gateway** → باید دوباره وصل بشه (توکن ربات رو دوباره وارد کن با `hermes gateway auth telegram`).

5. **MT5 مسیرها** → اگه مسیر MT5 روی سرور جدید فرق کرده، اسکریپتهای `mt5_*.py` رو ادیت کن (مسیر `terminal64.exe`).
