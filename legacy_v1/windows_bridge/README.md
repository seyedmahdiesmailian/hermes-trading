# Windows Bridge — فایلهای مستقر روی ویندوز

این پوشه فایلهای بریج MT5 روی باکس ویندوز را نگه میدارد (کشیده‌شده از
`C:\Temp` روی ۱۹۲.۱۶۸.۱۰.۵۱). چون «دستِ اجرای ترید» روی ویندوز زندگی میکند
و قبلاً کنترل نسخه نداشت، اینجا تاریخچهٔ مرجع است.

## ⚠️ کدام فایل کانُنیکال است (مهم — این بخش تا AUDIT-2026-10-04 اشتباه بود)

**`scripts/mt5_http_server_v2.py` فایل کانُنیکال و تنها چیزی است که deploy
میشود.** اگر بریج روی ویندوز تغییر کند، آن فایل را در ریپو تغییر بده.

این پوشه یک **اسنپشات تاریخی** از یک کپی قدیمی است که قبل از
review-fix ۲۰۲۶-۰۹-۱۷ ساخته شد — یعنی قبل از اینکه جریون استقرار یک‌طرفه
(git → ویندوز) برقرار شود. بخش «فایل LIVE است» در زیر نشان‌دهندهٔ
آخرین اجرا قبل از آن اصلاح است و دیگر درست نیست:

- **`bridge.py`** ← کپی قدیمی، دیگر کانُنیکال **نیست**. این همان چیزی است که
  روی ویندوز اجرا میشد تا ۲۰۲۶-۰۹-۱۷؛ از آن زمان
  `scripts/mt5_http_server_v2.py` جای آن را گرفته است. دربارهٔ کانال‌های
  `/api/pending` و `/api/cancel` همیشه با کانُنیکال همخوان نبود.
- `mt5_http_server_v2.py` و `mt5_http_server.py` و `mt5_http_server_fresh.py`
  و `bridge_backup.py` ← **حذف شدند در AUDIT-2026-10-04** (کپی‌های مرده
  داخل این پوشه که فقط باعث استقرار اشتباه میشدند). نسخهٔ زنده
  در `scripts/` است.
- `bridge_watchdog.bat` ← لانچر/watchdog که بریج را نگه میدارد.

## قرارداد

- اگر بریج ویندوز تغییر کرد، `scripts/mt5_http_server_v2.py` را تغییر بده —
  نه این پوشه را. استقرار با `scripts/_deploy_bridge.py` انجام میشود و
  فقط آن فایل را می‌خواند.
- هرگز توکنها را اینجا نگذار؛ توکن فقط در `.env` (لینوکس) و متغیر سیستمی
  ویندوز است.
- اگر روزی خواستی این پوشه را به طور کامل حذف کنی، اول
  `tests/test_b36_bridge_fixtures.py` و `test_bridge_canonical_auth.py` را
  بخوان — آن‌ها `scripts/mt5_http_server_v2.py` را AST-parse میکنند و
  شکل payload را پین میکنند.
