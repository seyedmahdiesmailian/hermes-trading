# Windows Bridge — نسخهٔ زندهٔ استقرار

این پوشه **آینهٔ واقعی فایلهای بریج MT5 روی ویندوز** است (کشیدهشده از
`C:\Temp` روی 192.168.10.51، 2026-09-19). چون «دستِ اجرای ترید» روی ویندوز
زندگی میکند و قبلاً **کنترل نسخه نداشت** (مشکل CRITICAL گزارش بررسی 2026-09-17)،
فایلهای حیاتی اینجا نگهداری میشوند تا ایجنتها دقیقاً بدانند چه چیزی واقعاً اجرا
میشود — نه چه چیزی «در نظر گرفتهشده».

## کدام فایل واقعاً LIVE است؟

- **`bridge.py`** ← فایل زندهٔ شنوندهٔ ۵۰۵۰ (پروسهٔ `pythonw C:\Temp\bridge.py`).
  این نسخه **Bearer auth** دارد (توکن از متغیر محیطی `HERMES_BRIDGE_TOKEN`
  خوانده میشود). فقط endpoint بررسی نشد در `Extra`-هایی که در اسکریپت هستند.
- `mt5_http_server_v2.py` روی ویندوز **بدون auth** است و **اجرا نمیشود** —
  فقط یک رفرنس قدیمی است. (توی ریپو `scripts/mt5_http_server_v2.py` هم رفرنسِ
  شکل payload داemonهاست، نه فایل زنده.)
- `bridge_watchdog.bat` ← لانچر/watchdog که بریج را نگه میدارد.

## قرارداد

- اگر بریج ویندوز تغییر کرد، فایل جدید را بهجای این پوشه برگردان و commit کن.
- هرگز توکنها را اینجا نگذار؛ توکن فقط در `.env` (لینوکس) و متغیر سیستمی
  ویندوز است.
