## ۳. زنجیرهٔ واقعی سیگنال

```
۷ کانال سیگنال (رادین، FX Golden، otsfx، ...)
        │  telethon (حساب کاربری، نه بات)
        ▼
forwarder/main.py  ──►  یک گروه واحد (-1002619945550)
   با پیشوند "[💬 از {نام کانال}]"، dedup، هندل edit/delete
        │  getUpdates بات
        ▼
signal_daemon → signal_listener → parser → ۷ چک → اجرا/رد/pending
```

این توضیح می‌دهد چرا `data/radin/` هفت فایل تاریخچه دارد و چرا `signal_listener.py` فیلتر b74g دارد: «فورواردر هر ۷ کانال را در یک گروه می‌ریزد و بعضی جفت‌ارز پست می‌کنند» — و کد **قبل از هر منطق قیمتی** روی متن ردشان می‌کند. طراحی درست است.

**نکته عملی:** سرویس `hermes-forwarder.service` به `/home/ai/projects/forwarder-telegram-dockerized` اشاره می‌کند، نه به `forwarder/` داخل ریپو. این پوشه **آینه است، نه کد اجرایی**.

### اثبات اینکه «شکست شنبه/یکشنبه» باگ نیست

```json

```

```

```
**موتور ریسک سالم است.** ولی سوئیت آخر هفته‌ها سبز نمی‌شود — این یک بدهی واقعی است.
